## 2. 計算流程（依使用指南＋VBA 實作）

**輸入** → 等價交通量 Q* → 基準點 LV10 → 加補正值 → 距離衰減 → 預測點 LV10_R → 與背景值合成、比對基準

### 2.1 等價交通量
```
Q* = (500/3600) × (1/M) × (Q1 + 12·Q2)      [輛/500s/車道]
V  = 0.5 × (小型車車速 + 大型車車速)
```

### 2.2 基準點振動位準（距最外側車道中心 5 m）
```
L = a·log(log Q*) + b·log V + c·log M + d   （VBA 先四捨五入至 0.1）
```

| 斷面 | a | b | c | d | 補正項 |
|------|--:|--:|--:|--:|------|
| 平面 | 65 | 6 | 4 | 35 | + ασ + αf(平) |
| 填方／挖方／路塹(凹槽) | 65 | 6 | 4 | 35 | + ασ + αf(平) + αs |
| 單柱高架 | 54 | 6 | 2 | 18 | + αHp + αf(高) |
| 雙柱以上高架 | 54 | 6 | 2 | 20 | + αHp + αf(高) |
| 平面高架併行（平面側） | 65 | 6 | 4 | **29** | + ασ + αf(平) |

平面高架併行：`LV10SV = 10·log(10^(L平/10) + 10^(L高/10))`

### 2.3 補正值
| 補正 | 公式 |
|------|------|
| ασ 路面平坦性（平面系） | 瀝青 14·log σ；混凝土 18·log σ；σ ≤ 1 時 = 0 |
| αHp 高架接縫高低差 | 0.4·log Hp |
| αf 平面系地盤卓越頻率 | f ≥ 8：−20·log f；4 ≤ f < 8：−18；f < 4：−24 + 10·log f |
| αf 高架 | f ≥ 8：−5·log f；4 ≤ f < 8：−4.5；f < 4：−6 + 2.5·log f |
| αs 道路構造 | 填方 −1.4H − 1.3；挖方 −0.87H − 1.7；路塹 −4.7H + 5.9；平面／高架 0 |

### 2.4 距離衰減
```
αl = β · log(R/5 + 1) / log 2          LV10_R = LV10 − αl
```
| 斷面 | β |
|------|---|
| 平面－黏土 | 0.060·L − 1.6 |
| 平面－砂質 | 0.119·L − 3.2 |
| 填方 | 0.077·(…) − 1.8 |
| 挖方 | 0.134·(…) − 3.2 |
| 路塹 | 0.058·(…) − 1.6 |
| 高架／平面高架併行 | 0.072·L − 2.2（併行用合成值 LV10SV） |

### 2.5 影響評估（摘要表）
- 合成振動量 = `10·log(10^(背景/10) + 10^(預測/10))`
- 振動增量 = 合成 − 背景（或有／無施工計畫差值）
- 與「評估基準」日／夜間值比較

## 3. 驗算結果

用 Python 照上述公式重算「輸入總表」裡全部 15 筆單一道路（平面）資料：
- **14 筆完全吻合**（LV10 與 LV10_R 誤差 < 0.1 dB）
- **1 筆不符**（第 4 列，台15線）：重算 LV10 = 58.9，表上是 58.7；但表上 LV10_R 58.2 跟重算一致。研判是車速改過以後，表上的 LV10 欄沒有更新。
- 51 筆「平面高架併行」資料的平面側和高架側分兩列寫入、欄位混用，這次只抽查了幾筆（例：台61線 L'V10(高) = 45.1 ✓、合成 48.2 ✓），沒有全部驗。

## 4. ⚠️ 發現的問題與待確認事項

### A. VBA 與使用指南不一致（需決定以哪個為準）
1. **αf 平面系 f < 4**：`RoadVIB_CAL.main_frequency` 寫成 `−24·log f`，指南是 `−24 + 10·log f`。平面高架併行分支和舊版 `土研交通振動.bas` 都是正確的。預設 f = 6，所以現有資料沒有受到影響。
2. **ασ 在 σ ≤ 1 時**：指南規定 = 0，表單版沒有處理（σ < 1 時會算出負值）。
3. **填方／挖方／路塹的 β**，三種寫法互相矛盾：
   - 指南：`0.077·(LV10f + αs) − 1.8`，但 LV10f 本身已經含 αs，αs 等於算了兩次
   - 表單版 VBA：`0.077·LV10f + αs − 1.8`（αs 沒乘係數）
   - 舊版模組：同指南
   → 建議對照日本原始文獻確認。現有資料沒有這三種斷面，所以還沒影響到成果。
4. **平面高架併行的平面側 d = 29**：指南寫 `LV10S_V = LV10S`（d = 35），程式和模式參數表都用 29。要確認是刻意的修正還是錯誤。
5. **αf 四捨五入**：VBA 把 αf 取整數，指南沒有提到要取整。

### B. 程式結構問題（改寫時順便修正）
- 公式和 UI 控制項綁在一起（`TB8`、`TB14a`…），而且 `On Error Resume Next` 會吞掉錯誤。
- 同一組選項鈕被重複拿來用：`Op1p2/Op2p2` 在計算裡代表橋腳數，在寫入總表時卻代表路面種類；`Op3p2` 有時代表瀝青、有時代表黏土。
- a、b、c、d 寫死在程式裡，跟「模式參數」表重複，兩邊可能不同步。
- 平面高架併行的平面側不會寫 TB8，所以總表的 LV10 欄會出現 0。
- 「與基準點距離」有負值（例：−1.1），要確認 R 的定義（是距基準點還是距車道）。
- 很多已經失效的具名範圍（#REF!）和舊版模組（`土研交通振動`、`AutoCal`、`autofm`）可以直接淘汰。

### C. 文獻版本提醒
指南的係數（例如平面黏土 β = 0.060L − 1.6）可能是舊建設省式的某個版本。印象中後來的修訂版（道路環境影響評価技術手法）係數不同，這點還沒查證，建議找原始出處確認後鎖定版本。

## 4.5 ✅ 公式定案（2026-11-18，使用者確認）

| # | 項目 | 定案 |
|---|------|------|
| 1 | αf 平面系 f < 4 | `−24 + 10·log f`（修正 VBA 的 −24·log f） |
| 2 | ασ σ ≤ 1 | `ασ = 0` |
| 3 | 填方／挖方／路塹 β | `β = 0.077·(LV10(平) + αs) − 1.8`（填方）；`0.134·(LV10(平) + αs) − 3.2`（挖方）；`0.058·(LV10(平) + αs) − 1.6`（凹槽）。其中 **LV10(平) = 平面道路基準值（含 ασ、αf，不含 αs）**，αs 只算一次 |
| 4 | 平面高架併行之平面側 d | 橋腳數 = 1 → d = 18；橋腳數 ≥ 2 → d = 20（取代原本的 d = 29）；a、b、c 沿用平面 65/6/4，即 `65·log(log Q*) + 6·log V + 4·log M + d` |

> 第 4 項影響：現有 51 筆併行資料的平面側基準值會降約 9～11 dB（d 29→18 或 20），重新計算後結果會和舊 Excel 不同，屬預期差異。

## 4.6 批次計算規則（網頁版，2026-11-18）

| 項目 | 規則 |
|------|------|
| 資料來源 | xlsm／xlsx 的「道路」「敏感受體」工作表（依表頭名稱讀取，欄位順序可變） |
| 道路分組 | 運輸道路去掉「_模擬狀況」後取路名前綴＋路段為一條道路；模擬狀況拆成「現況／無計畫／有計畫」＋時段（晨峰／昏峰） |
| 車速 V | （小型車車速＋大型車車速）÷ 2 |
| 平坦性欄 | 平面系當 σ，高架當 Hp |
| 併行配對 | 橋腳數 0 為平面側、≥1 為高架側；依路段「與ＸＸ併行」自動配對，可在配對表手動改；平面側 d 依夥伴高架側橋腳數 |
| 道路 × 受體 | 使用者在配對表手動勾選（使用者決定） |
| 現況修正 | 修正量 = 受體現況日間背景值 − 同時段現況預測值，加到無／有計畫預測值；可關閉（使用者決定）。**每個時段用自己的現況預測值**（舊版昏峰沿用晨峰修正量，兩者會有 ±0.4 dB 差異） |
| 施工摘要表 | 無施工計畫＝無計畫修正後；有施工計畫＝有計畫修正後；增量＝有－無；基準＝受體日間評估基準 |
| 營運摘要表 | 營運期間背景＝受體「營運日間背景值」（為 0 或空白時改用現況背景值）；營運期間環境振動量＝有計畫修正後；合成＝兩者能量合成；增量＝合成－營運背景。**此對應為暫定，待使用者確認** |
| 數值 | 各預測值先四捨五入至 0.1 dB 再相加減，使報表數字可直接驗算 |

驗證：台15線(港區～大崁腳加油站)／中華路一段附近民宅 晨峰 無 49.3、有 50.6、增量 1.3，與舊版施工摘要表一致；臨港大道／商港路公務機關 55.5／55.9（舊版 55.4／55.9）。
